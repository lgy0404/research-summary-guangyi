# 刘广义面试 PPT · 视觉设计稿

## 场景定位
互联网大厂人才计划实习面试 / 技术专家受众 / 10-15 分钟陈述。**走通用设计原则**，融合学术严谨与工业界专业感。

## 1. 画布与母版
- 画布：1280 × 720 px
- A · 标题块：0–120px（上 padding 20px；左右 padding 70px）
- B · 内容区：120–660px（540px 可用）
- C · 页脚条：660–720px（左侧 "Guangyi Liu · ZJU · 面试陈述"，右侧页码 NN/TOTAL，14px，#94A3B8）
- 左右 padding：70px

## 2. 色彩系统（4 hex 上限）

| 角色 | Hex | 用途 |
|---|---|---|
| 主色（primary） | `#1E40AF` 深蓝 | 大色块、章节页背景、强调数字 |
| 辅色（secondary） | `#3B82F6` 中蓝 | 卡片头部、图标、次级强调 |
| 强调色（accent） | `#F97316` 暖橙 | 仅用于关键数字、亮点、CTA、重要标签（≤10%） |
| 中性（neutral） | `#0F172A` 深文字 / `#64748B` 次文字 / `#F1F5F9` 浅底 | 文本与卡片底色 |

### 渐变方案
- 主渐变：`linear-gradient(135deg, #1E40AF 0%, #3B82F6 100%)` —— 封面右侧色带、章节过渡页背景、巨型数字背景
- 浅覆盖：`rgba(30,64,175,0.06)` —— 卡片浅底

### 面积分配（每页映射）
- Hero 页（封面/研究方向）：主色 ≤ 40%，强调色 ≤ 18%
- Supporting 页（教育/实习/论文/荣誉）：主色 ≤ 25%，强调色 ≤ 5%
- 过渡页：主色 ≥ 70%（大面积深蓝背景）

## 4. 密度门禁
- 内容页正文 ≥ 180 字（除过渡页）
- 卡片组页 ≥ 3 卡，每卡 ≥ 100 字
- 常规页留白 ≤ 35%；Hero 页 ≤ 45%
- 每页 ≥ 1 个视觉锚点（巨型数字 / 大图 / 大色块 ≥ 44px）

## 5. 配图等级
- L1 主视觉：封面 profile.jpeg（右侧骑线布局）；研究方向页用 SVG 框架图（结构化概念图允许 SVG）
- L2 支撑图：实习经历页 vivo-logo.png / kuaishou-icon.png；教育背景页 zju-logo.png / cumt-logo.png
- L3 角标：无（保持简洁）
